# Fintech — Dashboard (HTML, CSS e Bootstrap)

Tela de dashboard de uma fintech, feita na FIAP (Análise e Desenvolvimento de Sistemas) para praticar layout responsivo.

- Cards de resumo com entradas, saídas e saldo restante
- Bloco de principais gastos com gráfico em CSS puro
- Grid responsivo com Bootstrap 5 e estilos próprios em `css/style.css`

Para ver, abra `index.html` no navegador.
